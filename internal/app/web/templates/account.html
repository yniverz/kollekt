KI-Assistenten (MCP)

KI-Assistenten wie Claude greifen über das Model Context Protocol auf Kollekt zu. Sie sehen und ändern genau das, was du hier sehen und ändern darfst. Lesezugriff reicht für Fragen und Auswertungen. Gib Schreibzugriff nur, wenn der Assistent auch Einträge anlegen oder ändern soll.

Verbinden mit Anmeldung (empfohlen)

In Claude (Web, Desktop, Mobil) unter Einstellungen → Konnektoren einen eigenen Konnektor mit dieser Adresse hinzufügen, in Claude Code mit claude mcp add --transport http kollekt {{.MCPURL}} und danach /mcp. Claude öffnet dann die Kollekt-Anmeldung, und du entscheidest dort über Lese- oder Schreibzugriff.
